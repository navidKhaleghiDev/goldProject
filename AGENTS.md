# Project agent instructions

For e-commerce design, storefront UI, UX, conversion optimization, merchandising, cart, checkout, accessibility, or responsive shopping-flow tasks, read and follow `.agents/skills/ecommerce-ui-ux/SKILL.md` completely before acting. Load only the reference files linked from that skill that are relevant to the current task.

For frontend engineering with Next.js, React, TypeScript, React Hook Form, Yup, Axios, Zustand, shadcn/ui, Tailwind CSS, or TanStack React Query, read and follow `.agents/skills/nextjs-frontend-engineer/SKILL.md` completely before acting. Load only its references relevant to the current task.

When a request crosses two or more of e-commerce UX, frontend, backend, database, or API concerns, read and follow `.agents/skills/ecommerce-feature-workflow/SKILL.md` first. Let it coordinate the specialized skills and the shared feature contract.

For backend architecture or implementation involving the Express API, PostgreSQL, authentication, authorization, catalog, inventory, carts, orders, payments, shipping, refunds, jobs, uploads, or backend tests, read and follow `.agents/skills/ecommerce-backend-development/SKILL.md` completely before acting.

For end-to-end commerce features, combine the relevant skills without duplicating responsibility: the e-commerce UI/UX skill defines the customer experience, the Next.js frontend skill owns browser and frontend architecture, and the backend skill owns authoritative business, financial, inventory, security, and persistence behavior.
